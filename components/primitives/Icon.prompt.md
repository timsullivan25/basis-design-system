Small Lucide glyph that inherits text color — use it anywhere a label needs context at a glance.

```jsx
<Icon name="trending-up" size={14} />
<Icon name="alert-triangle" size={12} color="var(--text-caution)" />
```

Sizes: 12 in table cells, 14 inside buttons/inputs, 16 in nav and section headers. Never exceed the adjacent font size. Names are Lucide kebab-case.
